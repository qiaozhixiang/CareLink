📖 完整操作流程
1
编译生成新 APK

在 Android Studio 中编译 Debug 或 Release 版本，导出 APK 文件。

2
打开本页面，填入服务器地址

确保服务器后端已启动（java -jar 运行中），点击"检测连接"验证。

3
切换到"上传新版 APK"标签

点击上传区域选择 APK 文件，填写版本号、Version Code 和更新说明。

4
点击"上传并发布新版本"

APK 上传到服务器，版本信息写入数据库，全程自动完成。

5
用户打开 App 自动检测更新

App 登录后自动调用版本检测接口，发现新版本弹出更新提示框。

⚠️ 注意事项
1. 每次发布新版本前，需确保 Version Code 比上一次大（整数递增）
2. APK 文件会上传到服务器 C:/carelink/uploads/apk/ 目录
3. 本管理接口目前无密码保护，建议仅在内网或通过 VPN 访问
4. 强制更新会阻止用户跳过，建议非紧急情况不开启
🔧 手动操作（备用）

如果不想用网页，也可以直接操作数据库或调用 API。

① 直接操作数据库（宝塔 → phpMyAdmin） 
-- 修改版本号（versionCode 必须大于当前）
UPDATE app_configs SET config_value = '12' WHERE config_key = 'app.version_code';
UPDATE app_configs SET config_value = '1.2.0' WHERE config_key = 'app.version';
UPDATE app_configs SET config_value = '优化性能，修复已知问题' WHERE config_key = 'app.update_message';
UPDATE app_configs SET config_value = 'http://140.143.139.16:8080/api/admin/download-apk/你的APK文件名.apk'
  WHERE config_key = 'app.download_url';
② cURL 命令行方式 
# 上传 APK（PowerShell 格式）
$body = @{
    file = Get-Item "C:\path\to\app-debug.apk"
    version = "1.2.0"
    versionCode = 12
    message = "优化性能"
    forceUpdate = "false"
}
Invoke-RestMethod -Uri "http://140.143.139.16:8080/api/admin/upload-apk" `
  -Method Post -Form $body
③ 手动上传 APK + 修改版本

将 APK 文件复制到服务器 C:/carelink/uploads/apk/ 目录，
然后用宝塔 phpMyAdmin 在 app_configs 表中手动更新 4 条记录。
